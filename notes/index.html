    Import from iPhone Notes

    Create the shortcut Send to Trieu's Note once in the Shortcuts app:

    1. Tap + to create a new shortcut and name it Send to Trieu's Note.
    2. Tap ⓘ (Details) and turn on Show in Share Sheet. At the top, the shortcut now shows Receive … from Share Sheet: tap it and keep only Text and Rich Text.
    3. Add the action Make Markdown from Rich Text; its input should be Shortcut Input.
    4. Add URL Encode (input: Markdown from Rich Text).
    5. Add Text and paste https://theodore-ng.github.io/trieus-note/notes/#import&body=, then insert the variable URL Encoded Text right after the = (no space).
    6. Add Open URLs (input: Text). Tap Done.

    To use: in Notes, open a note → tap Share (or ⋯ › Send a Copy) → Send to Trieu's Note → Safari opens this page, tap OK. The first line becomes the title and the note is tagged #iPhone; sending the same note again does not create a duplicate.

    If the shortcut doesn't appear in the Share Sheet: select all text in the note and tap Share, or copy the note, replace the input of step 3 with a Get Clipboard action and run the shortcut from the Shortcuts app. The shortcut opens Safari, so you need to be signed in to Trieu's Note in Safari.

    Chọn một ghi chú hoặc bấm Mới.
